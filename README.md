# 高手科技 · GaoXTech

高手科技网站项目，内容方向包括 AI 实战、科技前沿和美股研究。

## 项目结构

- `site/`：网站源码与可部署项目
- `logo.png`：现有品牌头像
- `高手科技-iPhone文字壁纸.png`：现有品牌视觉参考

## 本地运行

```bash
cd site
npm install
npm run dev
```

## 构建与验证

```bash
cd site
npm run build
npm run test:sites
```

生产构建输出位于 `site/dist/`。项目已保留静态内容与后续动态工具、数据接口扩展的结构。
